# My Rental App - Promotional Website

A modern, professional promotional website for "My Rental App" - a vehicle rental application.

## 🌟 Features

- **Fully Responsive Design** - Works seamlessly on mobile, tablet, and desktop devices
- **Modern UI/UX** - Clean, professional design with smooth animations
- **5 Complete Pages** - Home, Features, Privacy Policy, Terms & Conditions, Refund Policy
- **SEO Ready** - Proper meta tags and semantic HTML
- **Easy to Customize** - Clear structure with well-organized CSS variables

## 🚀 Quick Start

1. **Clone or download this repository**
2. **Open `index.html` in your browser** - No build process required!
3. **Customize the content** - Update placeholders with your actual information

## 🎨 Customization

### Update App Store Links
Replace `#` in download buttons with actual URLs:
- App Store: Update in all pages (search for "Download on the App Store")
- Google Play: Update in all pages (search for "Get it on Google Play")

### Add Screenshots
Place your app screenshots in the `images/` folder and update the placeholder sections in `index.html`

### Update Contact Information
Replace placeholder contact details in footer:
- Email: `support@myrentalapp.com`
- Phone: `+1 (555) 123-4567`
- Address: `123 Rental Street, Tech City, TC 12345`

### Customize Colors
Edit CSS variables in `css/style.css`:
```css
:root {
    --primary-color: #2563eb;    /* Main brand color */
    --secondary-color: #10b981;  /* Accent color */
    /* ... more variables */
}
```
